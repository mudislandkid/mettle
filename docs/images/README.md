# Banner Image

This directory is for storing documentation images, including the banner image for the project.

## Banner Image Requirements

- Create a banner image named `banner.png`
- Recommended size: 1200x300 pixels
- Format: PNG or JPG
- Content: Include the project name "Mettle" and a visual representation of code analysis

## Example Design Ideas

- Code blocks with statistics overlaid
- Bar charts or graphs showing code metrics
- Programming language icons with Mettle metrics
- A minimalist design with the project name and a tagline

Once you've created your banner image, place it in this directory and it will automatically appear in the README.md at the project root.
