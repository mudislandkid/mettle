# Mettle desktop build

Native macOS app built with [Tauri 2](https://tauri.app/). The Vue frontend
is wrapped in a WebView; the FastAPI backend is shipped as a PyInstaller
sidecar that the Tauri shell spawns on launch and kills on quit.

```
   ┌────────────────────────────────────────────────────────────┐
   │  Mettle.app                                                │
   │                                                            │
   │   ┌──────────────────────────┐    spawn / kill             │
   │   │ Tauri (Rust)             │ ─────────────────────►      │
   │   │  - WebView (tauri://)    │                             │
   │   │  - Updater plugin        │   ┌────────────────────┐    │
   │   │  - Shell sidecar mgmt    │   │ mettle-sidecar     │    │
   │   └──────────────────────────┘   │  (PyInstaller exe) │    │
   │              │                   │  uvicorn + FastAPI │    │
   │              │  http://127.0.0.1:│  + alembic + SQLM  │    │
   │              ▼          random   └────────────────────┘    │
   │   ┌──────────────────────────┐                             │
   │   │ Vue / Vite bundle        │                             │
   │   │  loaded from tauri://    │                             │
   │   └──────────────────────────┘                             │
   └────────────────────────────────────────────────────────────┘
```

## Prereqs

- Rust + cargo (`rustup`)
- Xcode Command Line Tools
- Node 20+
- Python 3.12+ with `pyinstaller` (installed into `.venv` by the build steps)
- Tauri CLI: `cargo install tauri-cli --version "^2.0" --locked`

## Local builds

```bash
# 1. Build the sidecar (~35 MB binary)
.venv/bin/pyinstaller --clean --noconfirm \
  --distpath ./web/dist-sidecar \
  --workpath ./web/build-sidecar \
  web/sidecar.spec

# 2. Stage it with Tauri's target-triple naming
HOST=$(rustc -vV | sed -n 's|host: ||p')
# On Apple Silicon, rustc may report x86_64 if running under Rosetta —
# manually use aarch64-apple-darwin when the machine is M-series.
cp web/dist-sidecar/mettle-sidecar \
   web/frontend/src-tauri/binaries/mettle-sidecar-aarch64-apple-darwin

# 3. Build the .app and .dmg
cd web/frontend
npx tauri build --target aarch64-apple-darwin
# Output: src-tauri/target/aarch64-apple-darwin/release/bundle/{macos,dmg}/
```

For iterative dev work without a full bundle, use `npx tauri dev` —
this runs Vite on :5173 and points the WebView at it. The sidecar is
still spawned from `binaries/` so a fresh sidecar build is needed any
time the Python code changes.

## Updater

The desktop app polls
`https://raw.githubusercontent.com/mudislandkid/CodeCounter/release-manifest/latest.json`
on demand (the "Check for updates" button in the header). The manifest
is signed with the Ed25519 keypair generated by
`cargo tauri signer generate`.

- **Public key**: embedded in `web/frontend/src-tauri/tauri.conf.json`
  under `plugins.updater.pubkey` — committed.
- **Private key**: `.tauri-updater` at the repo root — `.gitignore`d, never
  committed. Stored in GitHub Actions as the secret
  `TAURI_SIGNING_PRIVATE_KEY` (paste the file contents verbatim).

### Private-repo authentication

While the repo is private, the updater can't fetch the manifest or
release assets anonymously. The Rust shell reads a fine-grained
**read-only** Personal Access Token via `option_env!("METTLE_UPDATER_PAT")`
at compile time and adds it as an `Authorization: Bearer` header to every
updater request.

The PAT lives in the GitHub Actions secret `METTLE_UPDATER_PAT` and is
baked into every shipped `.app` binary. **Anyone with a release artefact
can extract it**, so:

- Scope it tight: fine-grained PAT, **Contents: read-only**, **Metadata:
  read-only**, on `mudislandkid/CodeCounter` only.
- Rotate periodically (set a 90-day expiry).
- When the repo goes public, remove the `METTLE_UPDATER_PAT` secret —
  the `option_env!` branch in `lib.rs` falls through and the plugin
  registers without auth.

To create the PAT:

1. https://github.com/settings/personal-access-tokens/new
2. Resource owner: `mudislandkid`
3. Repository access: Only select repositories → `CodeCounter`
4. Permissions → Repository permissions:
   - Contents: Read-only
   - Metadata: Read-only (auto-granted)
5. Copy the `github_pat_...` value.
6. `gh secret set METTLE_UPDATER_PAT --repo mudislandkid/CodeCounter --body "<paste>"`

## Cutting a release

1. Bump the version in all four places:
   - `pyproject.toml` `[project].version`
   - `web/frontend/package.json` `version`
   - `web/frontend/src-tauri/Cargo.toml` `[package].version`
   - `web/frontend/src-tauri/tauri.conf.json` `version`
2. Commit the bump, tag, and push:
   ```bash
   git commit -am "release: v0.10.0"
   git tag v0.10.0
   git push origin main --tags
   ```
3. GitHub Actions (`.github/workflows/desktop-release.yml`) builds both
   `aarch64-apple-darwin` and `x86_64-apple-darwin` bundles, uploads them
   to the GitHub Release, and force-pushes a fresh `latest.json` onto the
   `release-manifest` branch.
4. Existing installs see the new version on their next "Check for
   updates" click, download the signed `.app.tar.gz`, verify the
   signature against the embedded public key, and relaunch.

## User data

The sidecar writes `mettle.db` to:

| Platform | Path                                                   |
|----------|--------------------------------------------------------|
| macOS    | `~/Library/Application Support/Mettle/mettle.db`        |
| Linux    | `~/.local/share/mettle/mettle.db`                       |
| Windows  | `%APPDATA%\Mettle\mettle.db`                            |

Updates replace the `.app` bundle, never the data dir — analysis history
survives across versions. Alembic migrations run on every launch.

## Auth in desktop mode

Every sidecar launch generates a random 24-byte hex token. Tauri reads
it from the sidecar's `MettleReady port=... token=...` stdout line and
hands it to the WebView via the `get_sidecar` invoke command. The
token modal never shows in desktop mode.

## CSP

The Tauri WebView CSP allows `connect-src http://127.0.0.1:* ws://127.0.0.1:*`
so the bundled frontend can talk to the sidecar on its random port.
